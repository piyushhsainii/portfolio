# Diversification contract

The user prioritizes genuinely different creative executions over lookalike headline swaps. Each selected concept has three visual/copy packages. Persona, angle, offer and awareness role remain stable within a concept; format, scene, composition and headline vary. This is exploratory creative development, not a causal hook experiment. After an execution earns sufficient signal, isolate the promising element in a controlled follow-up with one changed variable.

Review dimensions: buyer question, message, dominant visual premise, layout, environment, camera, product scale and format. A color swap or headline-only change does not count as a new execution here. The approved pack stays consistent for brand recognition. Contact-sheet review checks for accidental repeated compositions; source-file hashes establish file uniqueness only, not visual distinctness.

Meta’s engineering description identifies Andromeda as an ads retrieval system. It does not provide this project with a universal similarity threshold, an account score or a guarantee that assets will not be grouped. We do not fabricate a Meta Creative Similarity score or claim this portfolio bypasses ranking/retrieval. Direct access to the Business diversification page is recorded separately. No CPM, reach or conversion improvement is promised.

No ten-ads-per-concept volume or3xCPA heuristic overrides an affordable test plan. The current set is3perconcept/18total; Story adaptations do not count as extra hypotheses. Remaining V4 fixed-scene hook follow-ups and V5 persona/offer extensions are planned only, not rendered. User emphasis on diversity takes priority over the supplied suite’s standard V1–V3 headline-only convention.
