# STRANDVALE / Complete creative presentation

Open index.html in a browser. This is a local, buildless presentation with a black-and-white interface and full-color creative artwork. No network fonts or live checkout are needed. FOLDRINK remains a separate project.

The user approved packaging A: amber glass dropper, black cap, cream label and cobalt carton. Earlier B/C mockups are archived exploration, not current variants. STRANDVALE is a fictional US brand; name clearance is not completed.

Deliverables: six concepts × three exploratory execution packages = 18 finished feed ads with on-image hook, support and next step; 18 central-safe-area Story adaptations; five illustrative feed phone mockups; all five awareness levels; full copy and prompts; research/personas; economics, diagnostic and diversity notes; a 12-page PDF.

Folders: assets/campaign/source contains generated original complete artwork; masters contains 1080×1350 JPG and 600×750 WebP; stories contains 1080×1920 JPG. Story versions are placement adaptations, not new hypotheses. Text is rasterized; exact copy specifications and generation prompts are retained for revision. Packaging reference is assets/packaging/option-a.png.

Research → user packaging selection → concept/copy specifications → creative generation → review/export. Data records include sources, personas, assumptions and creative IDs. No additional human concept, policy or launch approval is implied by internal review.

Product assumptions: 30 mL is a design size. One 30 mL bottle / $29 first order / free US shipping / no subscription / tax extra is a proposed fictional introductory offer, not live. Formula, classification, safety, directions, sensory performance, efficacy and actual commercial terms are unknown. No hair-growth, reduced-hair-fall, finish or supply-duration claim is substantiated.

Creative diversity changes message, scene, layout, camera, scale and format while keeping the approved pack. These execution comparisons do not isolate a hook. No Meta account similarity score, guaranteed separation, Andromeda grouping avoidance or delivery result is claimed.

Start with index.html; use STRANDVALE-creative-presentation.pdf for a static overview. The ZIP contains the whole presentation and source specifications. Campaign performance remains untested.
